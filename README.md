# GestAL
Gestion de consulations animales pour les professionnels

## Technos
- Backend
  - Node.js
  - Express
  - Prisma

- Frontend
  - Vite
  - React
  - Tailwind CSS

- Database
  - PostgresSQL

## Ports
- Backend: http://localhost:3000/
- Frontend: http://localhost:5173/

## Commandes
```
~/GestAl/backend$ npm run dev
```
```
~/GestAl/frontend$ npm run dev
```
